# Beat Lab 🥁

A simple interactive **Drum Machine** built with HTML, CSS, and JavaScript.

## Features

* 9 interactive drum pads: `Q W E A S D Z X C`
* Play sounds by clicking pads or pressing keyboard keys.
* Displays the name of the triggered sound.
* Responsive design for desktop and mobile.

## Technologies

* HTML5
* CSS3
* JavaScript
* FreeCodeCamp Drum Audio Clips

## Files

```text
beat-app/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Usage

Open `index.html` in a browser, then click a drum pad or press its corresponding keyboard key to create beats.

Built as an educational FreeCodeCamp Drum Machine project.
